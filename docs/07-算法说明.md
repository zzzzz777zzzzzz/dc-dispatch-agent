# 七、算法说明

## 7.1 调度优化模型

### 7.1.1 问题定义

给定某数据中心一天的负荷曲线、新能源可用出力与分时电价，在满足设备物理约束与业务约束的前提下，
确定 96 个时段（每段 15 分钟）的运行方式，使综合运行成本最小。

### 7.1.2 决策变量

| 变量 | 含义 | 取值范围 |
| --- | --- | --- |
| `grid[t]` | 电网购电功率 | [0, 并网容量] |
| `pv[t]` | 新能源实际消纳功率 | [0, 可用出力] |
| `ch[t]` | 储能充电功率 | [0, 储能功率上限] |
| `dis[t]` | 储能放电功率 | [0, 储能功率上限] |
| `gas[t]` | 燃气轮机出力 | [0, 燃机容量] |
| `sh[t]` | 可延迟负荷在该时段的分配量 | [0, 转移阈值] |
| `soc[t]` | 储能荷电状态 | [SOC 下限, SOC 上限] |
| `z[t]` | 充电状态指示 | {0, 1} |
| `peak` | 全天购电峰值 | [0, 并网容量] |

### 7.1.3 目标函数

```
min  Σ_t [ (W_cost × price[t] + W_grid × grid_penalty + W_emit × carbon_price × EF_grid) × grid[t] × Δt ]
   + Σ_t [ (W_cost × gas_cost + W_emit × carbon_price × EF_gas) × gas[t] × Δt ]
   + Σ_t [ degrade_cost × (ch[t] + dis[t]) × Δt ] − Σ_t [ pv_bonus × pv[t] × Δt ]
   + W_demand × demand_charge × peak
```

其中 Δt = 0.25 小时。五项分别是购电成本、碳排成本、燃气燃料成本、储能损耗成本与最大需量电费；
`pv_bonus` 是光伏自用的额外奖励（负项即鼓励消纳）。需量电费的作用是抑制"把负荷全塞进谷段"造成的尖峰抬升。

**策略就是这组权重。** 目标函数只有一条，切换调度策略改的是 W_cost / W_emit / W_demand / grid_penalty / pv_bonus：

| 策略类型 | W_cost | W_emit | W_demand | grid_penalty | pv_bonus | 侧重 |
| --- | :---: | :---: | :---: | :---: | :---: | --- |
| `COMPREHENSIVE` | 1.0 | 1.0 | 1.0 | 0 | 0 | 成本优先 |
| `LOAD` | 1.0 | 1.0 | **3.0** | 0 | 0 | 削峰优先 |
| `MICROGRID` | 1.0 | **2.0** | 0.8 | **0.15 元/kWh** | **0.30 元/kWh** | 少买电、少碳排 |

**基线口径与策略无关**：基线始终是"储能闲置、新能源优先消纳、其余由电网与燃气承担"，
因此三条策略的节约率可以直接比较。计划落库时的成本 `opt_cost` 同样按原价计算，不含权重。

同站同日（北区 A，2026-11-10，基线 8,899 元）的实测差异：

| 策略 | 成本 | 峰值 | 全天购电 | 碳排 |
| --- | --- | --- | --- | --- |
| 成本优化 | 7,595 元（−14.7%） | 681 kW | 10,422 kWh | 6,857 kg |
| 负载均衡 | 7,968 元（−10.5%） | 536 kW | 9,657 kWh | 6,781 kg |
| 新能源优先 | 8,125 元（−8.7%） | 681 kW | 7,054 kWh | 6,419 kg |

### 7.1.4 约束条件

**功率平衡**（逐时段）
```
grid[t] + pv[t] + gas[t] + dis[t] = rigid[t] + sh[t] + ch[t]
```
其中 `rigid[t] = load[t] × (1 − deferrable_ratio)`。

**可延迟电量守恒**（按 4 小时调度块）
```
Σ_{t ∈ block} sh[t] × Δt = Σ_{t ∈ block} load[t] × deferrable_ratio × Δt
```
这条约束是本产品的核心：算力负荷可以在块内任意挪动，但总量不变，业务不受影响。

**储能荷电状态动态**
```
soc[0]   = soc_init + (η_ch × ch[0] − dis[0] / η_dis) × Δt / E_cap
soc[t]   = soc[t−1] + (η_ch × ch[t] − dis[t] / η_dis) × Δt / E_cap
soc[T−1] ≥ soc_target
```

**充放电互斥**
```
ch[t]  ≤ P_max × z[t]
dis[t] ≤ P_max × (1 − z[t])
```

**燃气轮机爬坡**
```
|gas[t] − gas[t−1]| ≤ ramp × Δt × 60
```

**新能源消纳率下限**
```
Σ_t pv[t] ≥ ratio × Σ_t pv_avail[t]
```
该约束为软约束：若导致不可行，自动放宽并在计划备注中记录。

**峰值定义**
```
peak ≥ grid[t]   ∀t
```

### 7.1.5 求解

- 求解器：OR-Tools 9.11，CBC 分支（`MPSolver.createSolver("CBC")`）
- 规模：96 时段 × 8 类变量，约 770 个变量、290 条约束，其中 96 个 0-1 变量
- 时间限制：20 秒（实测 38–60 ms 即达最优）
- 状态：`OPTIMAL` / `FEASIBLE` / `INFEASIBLE`

### 7.1.6 基线定义

基线代表"不做任何调度"的运行方式：

- 储能不动作（充放均为 0）
- 新能源优先消纳（`min(可用出力, 负荷)`）
- 剩余负荷由电网承担，超过并网容量的部分由燃气轮机补足
- 成本口径与优化方案一致，含燃料成本与需量电费

基线不依赖任何求解，可手工复算，因此结论可被外部核对。

## 7.2 负荷预测模型

### 7.2.1 评估方法

留出法（hold-out）：历史序列的最后一天（96 点）作为验证集，其余作为训练集。
训练与验证严格按时间切分，不做随机划分，避免未来信息泄漏。

```
MAE  = mean(|ŷ − y|)
RMSE = sqrt(mean((ŷ − y)²))
MAPE = mean(|ŷ − y| / |y|) × 100%
```

### 7.2.2 四个模型

**季节性朴素（SEASONAL_NAIVE）**
```
ŷ[n + h] = y[n − 96 + h]
```
以前一日同一时刻的值作为预测。作为基线，任何模型都必须优于它才有意义。

**同时刻移动平均（MOVING_AVERAGE）**
```
ŷ[n + h] = mean( y[n − 96k + h] ),  k = 1..3
```
取最近 3 日同一时刻的均值，抑制单日扰动。

**谐波特征线性回归（LINEAR_REGRESSION）**
```
ŷ = β₀ + Σ_{k=1..3} (aₖ sin(2πkh/96) + bₖ cos(2πkh/96)) + c₁ y[n−96+h] + c₂ y[n−192+h]
```
共 9 个特征，用最小二乘求解，正规方程以高斯消元法求解（带部分主元）。

**季节性指数平滑（HOLT_WINTERS）**
三次指数平滑，加性季节项，周期 96：
```
L_t = α(y_t − S_{t−96}) + (1−α)(L_{t−1} + T_{t−1})
T_t = β(L_t − L_{t−1}) + (1−β)T_{t−1}
S_t = γ(y_t − L_t) + (1−γ)S_{t−96}
ŷ_{t+h} = L_t + (h+1)T_t + S_{t+h−96}
```
参数 α=0.35、β=0.05、γ=0.30。

### 7.2.3 实测结果

在 4 个数据中心、15 360 个训练点与 384 个验证点上：

| 模型 | MAE (kW) | RMSE (kW) | MAPE |
| --- | --- | --- | --- |
| 同时刻移动平均 | 15.16 | 20.05 | 2.46% |
| 季节性朴素 | 18.23 | 24.08 | 2.93% |
| 谐波线性回归 | 23.59 | 30.25 | 3.63% |
| 季节性指数平滑 | 31.59 | 43.17 | 4.85% |

三个非朴素模型均优于朴素基线，说明模型确实学到了日周期之外的结构。
移动平均最优，反映该数据集日间形态高度稳定；Holt-Winters 误差最大，原因是偶发批处理作业的尖峰
对指数平滑更新构成扰动——这也说明"多模型对比 + 选优"的策略是必要的。

## 7.3 数据预处理算子

| 算子 | 实现要点 |
| --- | --- |
| 均值填充 | 按列计算有效值均值，仅替换缺失位置 |
| 中位数填充 | 排序后取中位；偶数个样本取中间两值平均 |
| 线性插值 | 按有效样本的索引位置分段线性估计；首尾缺失取最近有效值 |
| IQR 剔除 | Q1 取 25% 分位、Q3 取 75% 分位，剔除 [Q1−1.5IQR, Q3+1.5IQR] 之外的行 |
| Z-Score 剔除 | 剔除 \|z\| > 3 的行；标准差为 0 时跳过 |
| Min-Max | (v − min) / (max − min)；极差为 0 时输出 0 |
| Z-Score 标准化 | (v − μ) / σ；σ 为 0 时跳过 |

所有算子自动跳过日期列与非数值列，避免在真实业务表格上因类型转换失败而中断。

## 7.4 数据模拟器

用于生成可复现的历史数据。核心构成：

| 成分 | 建模方式 |
| --- | --- |
| 日周期 | `1 + 0.17 sin(2π(h−9)/24) + 0.05 sin(4π(h−9)/24)` |
| 周周期 | 周末系数 0.86 |
| 随机扰动 | ±3.5%，由哈希生成 |
| 制冷负荷 | `IT × 0.30 × (1 + 0.025 × (T − 24))` |
| 批处理冲击 | 约 1.5% 的时段触发，持续 4 段，叠加 5% 装机 |
| 光伏 | `装机 × sin(π(h−6)/12) × 云量系数`，雨天衰减 55% |
| 电价 | 谷 0.35 / 平 0.68 / 峰 1.05 |

随机数由 `hash(dcCode, epochDay, slot)` 生成，不依赖时间也不依赖调用顺序，
因此同参数下重复生成结果逐字节一致，满足实验复现要求。

## 7.5 计算复杂度与可扩展性

| 环节 | 复杂度 | 备注 |
| --- | --- | --- |
| MILP 求解 | 96 时段约 770 变量 | 时段数翻倍仍可在秒级求解 |
| 预测评估 | O(n) 每模型 | 15 360 点耗时 < 20 ms |
| 数据生成 | O(days × 96 × dc) | 41 天 4 站约 15 700 点，40 秒（受批量插入限制） |

若扩展到小时级（24 时段）或 5 分钟级（288 时段），只需改 `SLOTS_PER_DAY` 与 `STEP_HOURS`，
模型结构与代码无需变动。
